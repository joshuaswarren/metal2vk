## What works

- Device selection (`M2V_DEVICE`), feature enabling per `m2v-run.c`: 16-bit
  storage (8/16), float16/int8, subgroup size control + full subgroups,
  timeline semaphores, buffer device address, scalar block layout;
  VK_KHR_cooperative_matrix and VK_KHR_push_descriptor enabled only when the
  device offers them; instance debug utils when the loader has it.
- Buffers: host-visible coherent, persistently mapped; shim-owned VA space,
  16 KiB aligned, interval map with `Device::resolve` (unit tested:
  alignment, uniqueness, never-reuse, drop semantics). No
  SHADER_DEVICE_ADDRESS usage: `gpu_address()` is the shim's virtual handle.
- `.m2vlib` parser with clear magic/version/range/alignment errors (unit
  tested) and the reference emitter `host/tools/make-m2vlib.py`
  (fixed-point json/spv-offset packing, module push_constant_regions
  covered) + `host/tools/make-add-m2vlib.sh` running the repo's
  clang→sed→clspv chain and `m2v-reflect.py`.
- Pipelines: spec constants 0..2 (workgroup size) + Metal function constants
  (typed, clear errors - unit tested); dynamic threadgroup memory specialised
  through cached pipeline variants on the queue.
- Queues: one waiter thread per queue, FCFS submits, fence with
  `M2V_MAX_SUBMIT_MS` deadline (error in Completion on timeout), GPU
  start/end from timestamp query pools (timestampPeriod applied), pooled
  command buffers recycled at completion, timeline events.
- Dispatch: push descriptors when available with `M2V_NO_PUSH_DESCRIPTOR=1`
  escape hatch (see driver notes), per-command-buffer fallback pool;
  `set_address`/`set_bytes`/`set_threadgroup_memory_length`, the three
  dispatch forms, fill/copy with Vulkan's 4-byte alignment in the errors,
  barriers, debug groups (no-op without VK_EXT_debug_utils). Pipeline is
  bound at every dispatch.
- C ABI `src/capi.rs` (m2v_status + thread-local `m2v_last_error()`), header
  `include/metal2vk.h` generated by cbindgen through `build.rs`, checked in.
- Zig demo `host/examples/zig/demo.zig` (`@cImport`s the header, runs add,
  verifies, prints PASS).

  descriptors on G14C are suspected but not isolated - the G14C crash had
  the same missing-bind root cause.
